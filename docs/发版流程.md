# 发版流程

发一个新版本要走完下面全部步骤。**少一步，就有一批用户拿不到新版**：

| 发到哪 | 谁从这里拿 | 少了会怎样 |
|---|---|---|
| GitHub Releases（`ueboxai/uebox`） | 已装的用户「检查更新」（electron-updater 读 `latest.yml`） | 老用户永远收不到更新 |
| R2 对象存储（`dl.uebox.ai`） | 官网下载按钮、新用户 | 官网还在发旧版 |
| GitHub Releases（`ueboxai/unreal-agent-link`） | 单独装插件的用户（不经过盒子） | 插件源码改了却没发，单装的用户停在旧插件 |

出包天生是本地的（要给 UE 5.0–5.8 各编一遍插件，CI 装不下引擎），所以这几步都在维护者机器上跑。
三个发布脚本默认只演练、不动网络，确认无误再加 `--publish`。

## 1. 代码就位

- 要发的分支都合进 `main`，工作区干净（`git status` 没有别的会话的半成品 —— 打包读的是工作区）。
- 更新日志：从上一个 tag 汇总（`git log v<上一版>..HEAD`），写进 `CHANGELOG.md` 新的一节。
  合并 PR 时不写，发版时统一写。
- 版本号：改 `package.json` 的 `version`。

## 2. 插件全套出包

```bash
node scripts/build-all-plugins.mjs      # 5.0–5.8 各编一遍，出 resources/plugins/*.zip
pnpm plugin:check:all                   # 九个包都要是「最新」
```

插件源码这一版有变化时，同时把 `plugin/UnrealAgentLink/UnrealAgentLink.uplugin` 的
`VersionName` / `Version` 升一档（见第 6 步）。

## 3. 全量门禁

```bash
pnpm verify
```

全绿才往下走。注意 Windows 上工作区文件被写成 CRLF 时，全量 lint 棘轮会爆出几千条
`Delete ␍`：那是换行符，不是新问题，把文件换回 LF 再跑。

## 4. 出安装包

```bash
pnpm build:win
```

产物在 `dist/`：`uebox-<版本>-setup.exe`、`.blockmap`、`latest.yml`，三个必须是同一次构建出来的。
第 2 步已经出过插件的话，`build:win` 会再编一遍；想省时间可以按 `package.json` 里 `build:win`
的顺序跳过 `plugin:build:all` 手动跑后面几步（用 `pnpm exec node`，保证是工程钉的 Node）。

## 5. 提交、打 tag、推送

```bash
git push origin main
git tag -a v<版本> -m "<版本>"
git push origin v<版本>
```

## 6. 发布（对外，不可撤销）

```bash
# ① GitHub Releases —— 检查更新读这里
pnpm release:app                          # 演练
pnpm release:app --publish --notes <这一版的更新日志.md>

# ② R2 —— 官网下载按钮读这里（dl/<版本>/ 和 dl/latest/ 各一份，外加 dl/manifest.json）
pnpm release:dl                           # 演练
pnpm release:dl --publish

# ③ 插件单独发布 —— 只有插件源码这一版变了才发，tag 取 .uplugin 的 VersionName
node scripts/release-plugin.mjs           # 演练
node scripts/release-plugin.mjs --publish
```

R2 需要 `.env` 里的 `R2_ACCOUNT_ID` / `R2_ACCESS_KEY_ID` / `R2_SECRET_ACCESS_KEY` / `R2_BUCKET` /
`R2_PUBLIC_BASE`（见 `.env.example`）；GitHub 两步复用本机 git 的凭据。

## 7. 发完核对

- `gh release view v<版本> --repo ueboxai/uebox`：非草稿、三个文件都在、大小和本地一致。
- `curl -sI https://dl.uebox.ai/dl/latest/uebox-setup.exe`：200，`Content-Length` 等于本地 exe 大小。
- `curl -s https://dl.uebox.ai/dl/manifest.json`：`version` 是新版本（官网 60 秒内跟上）。
- 插件发了的话：`gh release list --repo ueboxai/unreal-agent-link` 最新一条是这一版。
