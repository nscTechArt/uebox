# 故事与补素材

## 教学

观众应能知道前提、复现关键步骤、验证结果。先展示结果，再解释关键选择。
节点、参数、菜单使用真实截图；缩小后看不清就补局部截图或拆镜头。
没有录制的操作可用分步骤截图解释，不能声称是原始操作录像。

## 宣传

前几秒展示任务最有价值的结果。围绕一个成果组织证据，避免逐条念工具名或功能清单。
用真实前后对比展示改变。不能编造性能数字、完成时间、客户评价或未实现功能。
产品演示按“输入 / 操作 → 响应 → 结果”呈现能证明价值的最短过程，不只展示一张功能截图。
收尾给一个与用途相符的下一步，例如试用已展示的功能；链接或入口必须来自用户资料，不能编造。教学以验证方法结束，整活以包袱结束，不统一套宣传口号。
需要背景氛围时可适量补图；保持主体、色调一致。

## 创意

从真实任务中的反差、意外、反转选故事。可补夸张插画、表情反应和字幕包袱。
艺术加工不是任务证据；虚构段落清楚标为演绎，不把用户没说的话伪造成原话。
先用剪辑节奏、静帧放大和文案实现笑点。难以表达的动作才推荐短 AI 视频镜头。

## 画面与节奏

- 以任务已有画面和用户给定风格为准。补图沿用同一主体、色调和文字层级；不要求另建品牌系统或模板库。用户指定的标志、界面和产品外观不重新设计。
- 每段旁白有对应画面。一个镜头讲到多个操作时，优先拆成连续镜头，分别使用真实截图或对应视频片段；不要开头就把所有步骤挤在一张图上，也不要让同一张无关背景撑完整段讲解。
- composition 支持按时间自由设计画面、图层和 GSAP 动画；简单镜头支持静帧、轻微放大与淡入淡出。阅读参数和观察对比时保持稳定；只有放大能帮助看清主体时才使用 `zoom`，不为“显得动态”让每张图都运动。
- 原始截图不清晰时优先补拍局部，不靠持续放大掩盖低分辨率。相邻的前后对比尽量保持主体位置和尺度，方便观众看出变化。
- 允许有意的停留：成果展示、关键参数、笑点落下后留出观察时间。节奏随内容变化，不机械地每隔几秒换画面。

## 补素材判断例

| 缺口 | 默认行动 |
|---|---|
| 有最终图但少了开场背景 | 按任务主题补一张背景图 |
| 教学节点看不清 | 对当前真实成果补局部截图 |
| 只有结果没有中间过程 | 制作明确的结果图解，说明缺少原始过程 |
| 整活需要角色飞起来 | 先考虑插画和简单运动；确需连续动作时推荐 3～5 秒 AI 视频 |
| 用户说只用现有素材 | 停止补图，使用现有内容组织故事 |
| 音乐没配置 | 无配乐继续，字幕不受影响 |
