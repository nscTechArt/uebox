# 工具、技能与权限

决定它能碰什么、什么时候必须先问过你。

默认值是可以直接开工的，不用先来这页调一遍。等你遇到「这类活我不想让它碰」「每轮太贵」「这个工程输不起」再回来。

这页讲配置项。它能干什么见[助手能做什么](/guide/capabilities)，这些开关在运行时怎么起作用见[助手是怎么干活的](/guide/agent-loop)。

## 工具

**设置 → 工具**。

![设置 → 工具](/shots/settings-tools.png)

### 清单按类别折叠

| 类别               | 覆盖范围                                                          |
| ------------------ | ----------------------------------------------------------------- |
| **蓝图**           | 蓝图的图、成员、编译                                              |
| **材质**           | 材质图、参数、实例                                                |
| **场景与关卡**     | 关卡中的 Actor、关卡本身                                          |
| **内容浏览器**     | 查找资产、导入、重命名、移动、依赖、迁移                          |
| **编辑器**         | 视口、选择、保存、PIE、截图、输入                                 |
| **界面控件**       | UMG                                                               |
| **动画与过场**     | Sequencer、动画、网格                                             |
| **PCG 程序化**     | PCG 图                                                            |
| **C++ 与编译**     | 代码和构建                                                        |
| **系统与诊断**     | 控制台命令、Python、性能、崩溃、插件                              |
| **AI 生成**        | 生图、生视频、生 3D、任务转视频                                   |
| **盒子自己的工具** | 素材库、蓝图/材质库、工程、本机文件与命令行、联网与浏览器、知识库 |
| **其他**           | 未归入上述类别的                                                  |

虚幻相关的工具按工作内容分类，应用自身的能力合并为一类。AI 生成单独成类：该类工具会按次向外部服务商计费。

### 开关

每一项可以单独关闭，也可以通过类别开关整组操作。类别开关有三态：全开、全关、半开（组内部分开启）。半开状态下点击的结果是全开。

关闭的工具不会提供给模型。

### 不可关闭的工具

标记为「不可撤销」的工具无法关闭。这类工具由每一步的审批控制，不由本清单控制。

### 成本

清单上方显示「已开启 X / Y 个，每次对话大约多付 N token」。工具定义占用上下文，开启数量影响每轮成本。

开启「工具搜索」后该行变为「常驻 X / Y 个……其余用到时再加载」。

### 工具怎么送给模型（Beta）

保持默认的「**全都给**」，除非你确实在为每轮的 token 成本发愁。

| 档位               | 说明                                       |
| ------------------ | ------------------------------------------ |
| **全都给**（默认） | 每次对话带上全部工具                       |
| **用到才给**       | 只常驻一部分，其余由技能和搜索在需要时取回 |

「用到才给」省 token，代价是模型可能选错工具、或者压根没把需要的那个取回来 —— 换来的是它做错事，不是它做得慢。改完在你下一次发消息时生效，正在跑的任务不受影响。

### 第三方 MCP 的工具不在这里

第三方 MCP 服务带入的工具由 [MCP](/guide/mcp) 页面管理，不出现在本清单中。

## 技能

**设置 → 技能**。

![设置 → 技能](/shots/settings-skills.png)

技能是一段面向助手的做法说明，包含处理流程、已知问题和不适用的场景。

### 内置的 25 个

| 技能           | 范围                                         |
| -------------- | -------------------------------------------- |
| 摆放 Actor     | 在关卡中放置、查询、移动、修改参数、删除     |
| 关卡整理       | 将 Actor 归入大纲视图的文件夹                |
| PCG 散布       | 程序化散布，以及排查产出为 0 个实例的原因    |
| 内容导入与整理 | 导入、查找、批量重命名、命名规范、依赖、迁移 |
| 蓝图图编辑     | 在已有蓝图中编辑逻辑与管理成员               |
| 材质创作       | 创建材质、修改图、编译、实例、诊断           |
| 几何编辑       | 布尔、切割、简化、重拓扑、补洞、UV、碰撞     |
| 动画重定向     | 骨架之间重定向、测量姿势、预览               |
| UMG 布局       | 创建 Widget、放置控件、暴露变量、渲染预览    |
| Sequencer      | 运镜关键帧、诊断渲染问题、修复 Camera Cuts   |
| 白盒出概念图   | 截取视口画面传给生图模型                     |
| 任务转视频     | 将对话和成果生成为本地视频                   |
| C++ 工作流     | 改已有的类、编译并热重载（建类需手动）       |
| 系统诊断       | 控制台命令、Python、性能、崩溃、插件         |
| 编辑器检查     | 视口、工程设置、关卡构成、引擎配置           |
| 工程体检       | 体积/性能/资产问题审计，输出排序报告         |
| AI 做 3D 资产  | 生图 → image-to-3D → 清理 → Blender 修形     |
| 生图           | 生成和编辑位图                               |
| Blender 互联   | 导出到 Blender 修形再导回（仅 Windows）      |
| 资产库         | 检索和整理素材库                             |
| 知识库与工程   | 存取知识库、创建工程、整理工程库、导入资产   |
| 本机文件       | 列目录、查找文件、搜索内容、读写、执行 shell |
| 深度研究       | 拆分问题、检索、读取页面、输出带引用的报告   |
| 技能创作       | 将做法写成技能，或修正错误的技能             |
| 提反馈         | 将过程中的阻碍整理成缺陷报告                 |

每条技能的适用与不适用范围见[助手能做什么](/guide/capabilities)。

### 来源与开关

三种来源：**内置**、**插件**、**自己的**（用户编写，或助手自动保存）。清单可按来源筛选，也可搜索名称和说明。

每条可单独开关，在下次任务时生效。关闭的显示「已关闭」标记。

点开可查看正文，也可编辑：

- 编辑「自己的」技能会直接更新原文件
- 编辑内置技能会保存为自定义副本，应用更新不覆盖该副本；删除副本后恢复原版

「打开技能目录」跳转到对应文件夹。

::: danger 删除技能不可恢复
删除操作会移除该技能的整个目录。删除自定义副本只是恢复原版，不影响内置内容。
:::

读取失败时显示「读取失败：{原因}」，不显示为 0 条。

### 自动记住做法

助手把验证过的做法存成技能，下次同类任务直接用。默认「**先问我**」—— 它想记什么你先过一眼，这一档适合绝大多数人。

| 档位               | 行为       |
| ------------------ | ---------- |
| **关闭**           | 不自动保存 |
| **先问我**（默认） | 保存前确认 |
| **自动**           | 保存后通知 |

写入文件这一步仍受权限控制。

关闭时清单上标记「自动记住已关闭，技能未启用」。

## 权限

### 会话级：审批模式

在输入框附近切换，每条会话独立记录。四档，见 [AI 会话 · 审批模式](/guide/assistant#审批模式)。

### 全局：文件访问范围

**设置 → AI 助手 → 隐私 → 文件访问范围**。默认「整台电脑」—— 很多正经活（读一份外部表格、翻一个参考工程）都在 UE 目录之外。这台机器上有你不想让它看见的东西，再收窄。

| 档位                 | 范围                                                 |
| -------------------- | ---------------------------------------------------- |
| **整台电脑**（默认） | 本机文件，不含受保护的敏感目录                       |
| **仅虚幻相关**       | 已安装的引擎、已导入的工程、素材库；同样排除敏感目录 |

两档都排除敏感目录。该设置**不限制 shell 调用** —— 真正兜底的是敏感目录黑名单和每一步的审批。

调成「仅虚幻相关」后，够不着的时候助手会收到说明并告诉你，不会闷头绕路。

### 全局：允许编辑器截图

控制助手能否获取虚幻编辑器画面。关闭后助手只能通过查询接口获取场景信息。

### 全局：浏览器显示方式

助手访问网页时画面的显示位置：**嵌入助手**（默认）/ **独立窗口** / **隐藏**。

::: warning 「隐藏」只影响显示
隐藏画面不改变操作权限，助手仍可访问和操作网页。
:::

## 审批

- 审批超时五分钟按拒绝处理，未及时响应时显示「这一步被拒绝了」。
- 「需要确认时提醒」默认开启，见[通知](/guide/small-tools#通知)。
- 「本次会话都允许」只在当前会话有效。
- 并行执行时可能同时存在多条待确认项，逐条弹出，并显示「还有 N 条等确认」。
- 改档位**当场生效**：被确认框拦住时去把档位调松，本轮就少弹框，不必等下一条消息。
- 少数操作**每次都要当场批准**，不提供「本次会话都允许」—— 例如往网页里点击和输入，它们每次的参数都不一样，而参数本身就是风险。

被拒绝之后助手不会重试同一步，它会换一种做法或者问你希望怎么做。

## 给助手交代背景

**设置 → 个性化 → 给助手的说明**。

该段说明带入所有对话，用于描述工作内容、技术背景和沟通偏好。界面上给出的示例：

> 我是游戏公司的地编，主要做大世界场景搭建和优化。
> 我不写 C++，蓝图能看懂但不熟，别默认我会。
> 结论先说，过程我需要的时候会问。

也可以点「用默认文本编辑器打开」在外部编辑。该文本存在应用数据目录的 `instructions.md`。
