# 安装与更新

下载、装上、保持更新。全程不需要账号，也不用填任何信息。

## 下载

安装包发布在 GitHub Releases：<https://github.com/ueboxai/uebox/releases>

挑你系统对应的那个：

| 系统    | 文件                                                            |
| ------- | --------------------------------------------------------------- |
| Windows | `.exe` 安装包。这是主要支持平台                                 |
| macOS   | `.dmg`。M 系列芯片选文件名带 `arm64` 的那个，Intel 机器选另一个 |
| Linux   | 见 Release 页面的 Linux 产物。安装包不含 `uebox` 命令行工具     |

没有国内镜像，下载源只有 GitHub Releases 一处。国内访问慢是已知的 —— 双渠道和自建更新服务器都已经删掉了，这是知情的选择。

装完第一次打开会让你选一次界面语言，然后进入项目库。它会列出本机装了哪些虚幻引擎，但**不会扫你的硬盘找工程** —— 工程由你自己导入。完整的开机顺序见[第一次打开](/guide/first-run)。

## 更新

**设置 → 关于 → 检查更新**。三步各问你一次，每一步都可以选「稍后」：

| 步骤     | 提示                                         |
| -------- | -------------------------------------------- |
| 发现     | 「发现新版本 {版本}，现在下载吗？」          |
| 下载中   | 「正在下载更新，完成后会提示你安装」         |
| 下载完成 | 「新版本 {版本} 已下载完成，是否立即安装？」 |

下载完成后左上角出现「**新版本 ↑**」标记 —— 它标的是「已经下好了，随时可以装」，不是「有新版本」。

::: tip 为什么不自动下载
安装包几百 MB。替你决定要不要占带宽、占磁盘，在一个号称完全离线的应用里说不过去。所以发现新版本先问一句，安装也不会在你退出时偷偷执行。
:::

应用启动后会静默检查一次，之后每 4 小时再查一次；这两次都不弹窗，只更新状态。

取不到更新时有两种提示：「暂时无法获取更新，请稍后重试。」是取不到更新清单，「暂时无法连接更新服务器，请检查网络后重试」是连不上。

### 更新源

只有一条线：上述 GitHub 仓库的 Releases。由 `package.json` 的 `updateGithubRepo` 字段指定，也可以用 `updateFeedUrl` 指向自架的静态源。

::: warning 没配置更新源 = 一次网络请求都不发
这是社区版的硬规则。改过那个字段（例如打包自己的 fork）而没有填新的源时，构建出的版本**不带更新源**，连 electron-updater 都不会加载。

反过来也成立：第三方自己编译的版本不会被推送官方二进制。
:::

## 从源码构建

需要 [Node.js 24.21.0](https://nodejs.org/) 和 pnpm 10.28.2。

```bash
pnpm install
pnpm dev
```

首次 `pnpm install` 需要编译原生模块，耗时几分钟。打包与插件构建见[给开发者](/develop/)。

## 卸载

按系统常规方式卸载。卸载**不会**删除你的应用数据 —— 资产库索引、笔记、设置都在独立目录，见[文件都放在哪](/guide/where-is-my-data)。要彻底清干净，卸载后自己去那个目录删。
