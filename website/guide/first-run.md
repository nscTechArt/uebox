# 第一次打开

十来分钟配好，然后让它在你自己的工程里干第一件事。

装应用见[安装与更新](/guide/install)。第一次启动会让你选一次界面语言，之后可在 设置 → 外观 → 语言 改。

## 配好模型

必填项只有一个：**设置 → 模型 → 默认模型 → 对话**。

1. **设置 → 模型 → 添加服务商**，填 API 密钥。密钥加密存在本机，不经中转服务。
2. **设置 → 模型 → 默认模型**，把「对话」指向刚配好的模型。

其余角色（Agent、视觉、嵌入、生图、语音）等用到再配，每一项下方都标了不配会影响什么。

没有密钥也能开工：内置目录里的「本机推理」一组（Ollama、LM Studio、llama.cpp）跑在你自己机器上，不需要密钥。效果和速度取决于你的硬件，**模型必须支持工具调用**，否则操作不了引擎。详见[配置模型](/guide/ai-setup)。

## 接上你的工程

1. **项目库 → 导入 `.uproject`**。盒子不扫硬盘找工程，你得自己指给它。
2. **点「打开项目」**，连接插件会自动装上。

引擎列表是空的、显示「没有找到已安装的虚幻引擎」时，不代表你没装 —— 把引擎根目录（含 `Engine/Binaries/Win64/UnrealEditor.exe` 的那一层）拖进那块区域，或者点 `+` 手动添加。macOS 上直接拖编辑器的 `.app` 也行。

## 发第一条消息

**侧边栏 → AI 会话**，说清楚你要什么。几个够具体、一轮能看到结果的开头：

- 「这个关卡里有多少个光源？各是什么类型，分别在哪？」—— 纯只读，用来确认插件真的连上了
- 「把 `/Game/Props` 下面的资产按命名规范审计一遍，先给我清单，别动手」—— 批量操作本来就是先出清单再执行
- 「新建一个材质，基础色接一个参数，粗糙度 0.3，然后编译」

它默认跑在「帮我批准」档：自己动手，识别到风险操作时停下来问你。想让它只看不动，把档位调成「只读」。见[审批模式](/guide/assistant#审批模式)。

## 只想用素材管理

不配模型也能用，资产库是完整的独立工具：

1. **侧边栏 → 资产库**
2. **左上角库名 → 新建资产库**
3. 选模式：**引用原有文件** / **复制并归档**
4. 拖入文件或文件夹

两种模式的区别和取舍见[资产库](/guide/asset-library)。

## 它启动时做了什么

启动时它会扫描本机已安装的虚幻引擎列在项目库上方，并恢复你上次所在的标签页（没有可恢复的就进项目库）。

它不会扫你的硬盘找 UE 工程，也没有账号校验 —— 应用里根本没有登录入口。

网络动作只有一项：**如果这个安装包配置了更新源**，静默查一次有没有新版本，之后每 4 小时再查一次，见[更新源](/guide/install#更新源)。没配更新源的构建连这一次都不发。除此之外，只有你用 AI 功能（连你自己配的服务商）时才联网。
