# 3D 生成与查看器

看模型不用开引擎，生模型不用离开盒子。

## 3D 查看器

侧边栏「更多」里的 **3D 查看器**。把模型文件拖进来就能看，也可以点右上角选择文件。

空的时候显示「还没有模型，把文件拖进来，或点右上角选择」。

![加载了一个模型：左边视口，右边是光照、视角和模型信息](/shots/model-viewer-loaded.png)

![3D 查看器](/shots/model-viewer.png)

### 显示模式

工具栏上可以切换：

| 模式     | 看什么           |
| -------- | ---------------- |
| **默认** | 带材质的正常渲染 |
| **法线** | 法线方向         |
| **线框** | 拓扑结构         |
| **白模** | 去掉材质看形体   |
| **UV**   | UV 展开          |

另外两个开关：**自动旋转**、**播放动画**（模型带动画时）。

![线框模式](/shots/model-viewer-wireframe.png)

### 光照与视角

右侧面板还有两组：

**光照** —— 三个预设：**影棚** / **日光** / **暗房**，下面一条**亮度**滑块。看深色模型时切到日光通常更容易看清形体。

**视角** —— 两个按钮：

- **回到默认视角**
- **模型躺着？扶正它** —— 有些导出的模型 Z 轴朝向和 UE 不一致，进来是躺平的，点它转正

### 模型详情

面板里列出：文件格式、文件大小、顶点数、面数、材质数、网格对象、贴图数、包围盒。

可用于检查模型面数和材质槽数量。

### 截图更新缩略图

工具栏的「**截图更新缩略图**」把当前视角截下来当这份资产在资产库里的缩略图。

模型不在资产库里时这个按钮点不动，会说明「这个模型不在资产库里，没有可更新的缩略图」。

## 3D 生成

::: warning 没有独立的界面入口
3D 生成、视频生成这两项**没有专门的页面或按钮**，通过在 [AI 会话](/guide/assistant)里用自己的话要求来触发。

比如：「照着这张图做个底模」「生成一个石头的模型」。
:::

### 配置

**设置 → 模型 → 添加服务商 →「3D 生成」分组**。支持三种接口：

- **Hyper3D Rodin**
- **Tripo（VAST AI）**
- **Meshy**

添加模型时要勾「**3D 生成**」能力，并在模型设置里选对应的 **3D 接口**，然后按服务商的说明填模型 ID。没选接口时无法生成。

最后在「默认模型 → 3D 生成」里指向它。

### 费用

::: danger 生成可能几分钟，失败也可能扣费
计费规则以服务商为准。视频生成同理，而且单次更贵。
:::

### 重做需要用户确认

生成图片、视频、3D 模型均按次计费，而结果是否符合预期属于主观判断。因此助手不会自行决定重新生成 —— 它认为结果不理想时会询问，由用户决定是否重试。

### 结果去哪

生成完的模型自动导入当前保管库的 `AIGC\模型\<任务ID>` 目录，消息里有「查看模型」可以直接跳过去。

消息里还会带上优化后的提示词、原始提示词和任务 ID。

失败或超时都会明说是哪一种：

- **失败** —— 给出错误信息
- **超时** —— 「模型可能仍在生成中，请稍后手动查询任务状态」

## 从想法到模型的完整路子

单独一次 image-to-3D 通常做不出可用的资产。助手有一条专门的技能把几种能力串起来：

1. 生图出概念图和**互相一致的四视图**
2. image-to-3D 出底模
3. Geometry Script 做简单清理
4. Blender 做复杂改形（仅 Windows）

每一段结束都对着参考图核一遍再进下一段。

::: tip 两个已知的坎
堆基本体做不出有机造型；第三轮之后往往越改越差。所以这条流程强制要求拿参考图逐条比对，而不是凭感觉一直改。
:::
