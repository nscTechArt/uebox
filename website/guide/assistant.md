# AI 会话

跟 Agent 说话的地方：怎么下指令、它跑起来之后你能看到什么、改完怎么核对。

![AI 会话首屏](/shots/assistant-welcome.png)

用之前先[配置模型](/guide/ai-setup)。想让它操作引擎，还得让编辑器连上，见[连接虚幻引擎](/guide/plugin)。它能干什么见[助手能做什么](/guide/capabilities)。

## 两种模式

在输入框右下角切换。默认是 **Agent**：

- **Agent** —— 调用工具，一轮可能包含多个步骤。要它动工程就用这个。
- **Chat** —— 只对话，不调用工具，不修改工程。适合问路、理思路、让它解释一段蓝图是怎么回事。

## 输入框

### 斜杠命令

在输入框中输入 `/` 弹出「命令与技能」菜单，`↑↓` 选择，`Enter` 调用。菜单分两组：命令和技能，技能标注来源（内置 / 插件 / 用户）。

| 命令             | 作用                                                                                   |
| ---------------- | -------------------------------------------------------------------------------------- |
| `/goal <目标>`   | 目标模式 —— 做完自动复核，未达成则继续修改（[复核怎么跑](/guide/agent-loop#目标模式)） |
| `/image`         | 切到图片生成模式                                                                       |
| `/compact`       | 压缩当前会话的历史，释放上下文                                                         |
| `/wiki [关键词]` | 绑定知识库；`/wiki clear` 解绑                                                         |

### @ 提及来源

输入 `@` 可提及**知识库来源**和**笔记**。提及后输入框提示变为「针对 N 个来源提问...」。

### 附件

- **图片** —— 拖入或粘贴。需要模型支持「视觉」能力，或已配置「视觉」默认模型。
- **Excel** —— 有数量上限，单个文件最大 5 MB。
- **文档** —— 有数量上限。

### 按钮

| 按钮         | 说明                                    |
| ------------ | --------------------------------------- |
| **图片生成** | 进入生图模式，见 [AI 创作](/guide/aigc) |
| **目标**     | 目标模式，等同 `/goal`                  |

3D 生成和视频生成没有对应按钮，通过对话触发，见 [3D 生成](/guide/model3d#_3d-生成)。

## 会话级的三个开关

以下三项位于输入框附近，每条会话独立记录。

### Agent 模型

点击模型名可为当前会话切换 Agent 模型。任务运行期间无法切换，提示「当前任务结束后可切换 Agent 模型」。

没有可用模型时显示「前往模型设置」入口。

### 思考程度

八档：`auto`、`off`、`minimal`、`low`、`medium`、`high`、`xhigh`、`max`。默认 `auto`，绝大多数时候不用动它 —— 遇到反复改不对的复杂图再往上调。

档位名用模型声明的原始名称，不做翻译。每个模型实际支持哪几档由模型自己说了算。

选了模型不支持的档位时，提示「{模型} 没有 {所选} 这一档，本次实际按 {实际} 执行」。

### 审批模式

控制它动手之前问不问你。**默认是「帮我批准」**，大多数活就用这一档：它自己往前走，识别到风险操作时才停下来。

刚上手、或者这个工程输不起，先用「请求批准」，每次改工程都会等你点头。只想让它看不让它动，用「只读」。

| 档位                 | 说明                                 |
| -------------------- | ------------------------------------ |
| **只读**             | 仅查看和分析，无修改权限             |
| **请求批准**         | 修改工程和资产时始终询问             |
| **帮我批准**（默认） | 仅对检测到的风险操作请求批准         |
| **完全访问权限**     | 可不受限制地修改工程、资产和本地文件 |

档位是**每条会话各记各的**。在这条会话上调紧，不会被你在另一条会话上的选择推翻。

::: danger 「完全访问权限」有二次确认
确认弹窗逐条列出开放的范围：

- **虚幻工程** —— 创建、修改、删除关卡中的 Actor、蓝图、材质与资产
- **文件和资产库** —— 读取、写入、移动或删除资产库中的文件
- **引擎命令与脚本** —— 执行控制台命令、运行 Python 脚本、启用或停用插件

弹窗原文：「这会带来资产被误删、工程被改坏的风险。你可以随时改回来。」
:::

## 上下文窗口

输入框附近显示「上下文 {已用} / {总量}（{百分比}），超出后会自动压缩」。

压缩将前面的历史总结为一段摘要以释放空间，可自动触发（用满约 70% 时），也可用 `/compact` 手动触发。摘要保留什么、丢掉什么见[助手是怎么干活的 · 上下文与压缩](/guide/agent-loop#上下文与压缩)。

压缩完成后提示「已从 N 条压缩至 M 条，节省约 X token」。

无法压缩时的提示：

| 提示                                   | 原因                     |
| -------------------------------------- | ------------------------ |
| 正在处理这条对话，请稍后再压缩         | 有一轮正在运行           |
| 历史还太短，压了省不下什么             | 历史长度不足             |
| 压过一遍了，再压只会让摘要又被概括一层 | 已压缩过                 |
| 生成摘要失败，历史没有改动             | 摘要生成失败，历史未变更 |

## 运行过程

### 工具调用可见

每次调用工具显示工具名、参数和结果，可折叠。支持推理的模型显示「思考过程」。

![一轮真实对话：提问、工具调用摘要、开始作答](/shots/ai-conversation.png)

**查看它看的图（N）** —— 助手本轮查看过的截图默认收起，点开后加载。

![展开过程日志后：每一步调用了哪个工具、传了什么参数、返回了什么](/shots/ai-tool-call.png)

工具产出的截图可点开查看大图。

### 子任务泳道

助手拆分子任务时，每一路占一张卡片，显示「子任务 N」、状态（进行中 / 已完成 / 失败）和步数。多路并行时顶部显示「N 路子任务并行中」。

子任务什么时候会被派出去见[助手是怎么干活的 · 子任务](/guide/agent-loop#子任务)。

### 中途插话

运行期间可以直接在输入框发送消息，有两种处理方式（默认值在 设置 → AI 助手 → 运行中发送的消息 中设定）：

- **排队** —— 当前任务完成后处理。排队中的消息可以「取消这条」或「立即发送」。
- **插话** —— 当前步骤完成后调整方向。

已提交给模型的消息无法撤回，提示「晚了一步，这条已经发给模型了」。

显示「这条对话还有一轮在跑」时，等待其结束，或直接发送下一步说明。

### 助手的提问

助手不确定时显示「**需要你定一下**」卡片，提供若干选项。可以选择一项、选「其他（自己填）」、点「**你自己定**」由助手决定，或「关掉，先不答」。

多个问题时分步显示「N / M」，支持上一步和下一步。

### 操作确认

需要确认的操作弹出「**敏感操作确认**」，显示操作类型和风险等级。可以确认执行、拒绝，或选「**本次会话都允许**」放行同类操作。

同时存在多条待确认项时显示「还有 N 条等确认」，逐条弹出。

::: warning 审批超时五分钟按拒绝处理
因此「需要确认时提醒」默认开启，见[通知](/guide/small-tools#通知)。
:::

## 结果核对：三层

它说做完了，不等于真做完了。三层依次回答三个不同的问题：**它说它改了什么**、**工程里现在真是这样吗**、**这东西是不是你要的**。

### 第一层：本轮改动（它说它改了什么）

每轮回复下方列出本轮的改动，分两区：

- **引擎里的改动（N）** —— 每行格式为「[类型] 名字 [净结果]」，例如「材质 M_GlowBreath 新建」
- **引擎命令与脚本（N）** —— 控制台命令和 Python 脚本单独成区，这类操作没有对应的资产路径，按原文列出

类型包括：材质、蓝图、控件蓝图、关卡、Actor、资产、文件夹、文件、笔记、网页、插件。
净结果有五种：新建、修改、删除、启用、停用。

每行可以「打开」或「在编辑器中打开」，展开后可查看该步骤的明细。

![本轮改动：建了一个材质，标着「新建」，右边是「审查改动」和结论](/shots/engine-changes.png)

标记含义：

| 标记         | 含义               |
| ------------ | ------------------ |
| **不可回滚** | 该步骤无法撤销     |
| **未生效**   | 该步骤未成功       |
| **N 步失败** | 明细中存在失败步骤 |

文件类的改动可点「**审查**」查看 diff。文件超过 256 KB、不是 UTF-8 文本或读不到快照时，提示「文件已写入，但无法生成对比」。

### 第二层：审查改动（工程里现在真是这样吗）

点「**审查改动**」，应用拿只读工具回到引擎里核实一遍当前状态。

这问的不是第一层那个问题：工具返回了成功，材质仍可能没保存到硬盘，蓝图仍可能编译不过。

| 结论                               | 含义             |
| ---------------------------------- | ---------------- |
| 说是做好了，但工程里找不到它       | 未创建成功       |
| 说是删掉了，但它还在               | 未删除成功       |
| 改动还在编辑器内存里，没保存到硬盘 | 需要在 UE 中保存 |
| 蓝图编译报错，现在是坏的           | 需要修复         |
| 蓝图编译有警告                     | 存在编译警告     |
| 引用了不存在的资产                 | 存在断引用       |
| 删掉了，但还有资产在引用它         | 引用方会报错     |
| 命名和 UE 惯例不一致               | 命名不符合惯例   |
| 这一项没查成                       | 检查本身失败     |

::: warning 引擎未连接时结论不完整
提示为「引擎没连上，机器那一半没跑成 —— 别把『机器没说话』当成『没问题』。」
:::

### 第三层：让它自证（这东西是不是你要的）

点过审查后会自动追加一条「**已让它自证 ↓**」。

![审查结论：「查了 1 个资产，没发现问题」，后面跟着自证的要求](/shots/engine-review.png)

自动检查只能核实事实（资产在不在、编译过没过），判断不了结果符不符合你的需求。这部分由助手逐条回应，要求如下：

1. **不许凭记忆回答** —— 每一条都要用只读工具重新到引擎中查询，写出查到的实际值。调用成功的记录不作为证据。
2. 对自动检查查出的每个问题，说明是真实问题还是误报；误报需给出依据。
3. 回答自动检查无法覆盖的部分：产出是否符合需求，哪里未做到、哪里是助手自行添加的、哪里做了折中。无法做到的直接说明。
4. **本轮只说明，不执行修改** —— 修改会改变被核实的状态。

![自证回复：做到了什么、自己加了什么、哪里做了折中、这一轮没动任何东西](/shots/engine-selfcheck.png)

## 会话管理

侧边栏的会话列表见[界面导览](/guide/interface#ai-对话列表)。

### 分支

在任意消息上选「**从这条创建分支**」，从该处派生一条新会话，原会话不受影响。之后两条会话独立，内容不再互相同步。

当前会话不是 Agent 会话时无法创建分支。本轮尚未结束时也无法创建，提示「从更早的一条分支，或稍后再试」。

### 侧边问一句

「**侧边问一句（带上下文）**」打开一个携带当前上下文的小窗口。

与分支的区别：分支派生一条新会话并继续执行任务；侧边问一句用于询问当前状态，关闭后主对话不记录该次询问。

### 其他

- 编辑已发送的消息并重新发送
- 重新生成 AI 回复（仅限 AI 回复）
- 将回复保存为笔记
- 朗读回复（需配置「语音合成」模型）
- 导出对话
- 清空会话（不可撤销）

### 发送时的编辑器快照

发送消息时应用会记录编辑器中当前选中或打开的内容，附加在该消息上。鼠标悬停显示「发送时（时间）AI 看到的编辑器状态」，内容包括当时的 Actor、资产、节点数量；未选中任何内容时显示「当时没有选中任何东西」。

## Token 用量

每轮回复下方显示输入、输出、缓存读取、缓存写入和合计。配置了价格的模型会折算费用，按服务商的计费口径统计。

![回答末尾：token 用量、复制/重新生成/分支/朗读，以及追问建议](/shots/ai-answer.png)

完整统计在 **设置 → 用量**。

## 内置浏览器

助手访问网页时打开一块浏览器分屏，默认位于会话右侧（可在 设置 → AI 助手 → 浏览器显示方式 改为独立窗口或隐藏）。

支持调整宽度、在独立窗口中打开，以及手动操作（后退、前进、刷新、停止、输入网址、多标签）。

未配置「网页检索」服务商时使用该内置浏览器。

## 错误提示

| 提示                 | 含义                                                           |
| -------------------- | -------------------------------------------------------------- |
| 模型服务商余额不足   | 所配置的服务商返回余额不足。应用本身没有账户，不涉及应用的收费 |
| API 密钥无效或已过期 | 到 设置 → 模型 检查密钥                                        |
| 请求太频繁           | 服务商限流                                                     |
| 服务暂时不可用       | 服务商侧异常                                                   |
| 网络连接失败         | 检查网络、VPN、代理、模型地址                                  |

中止后可点「继续尝试」。原因不明确时提示「暂时无法确定具体原因，请检查模型连接后再试」。
