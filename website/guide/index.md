# 虚幻盒子是什么

给一个目标，让 AI 在你正在跑的虚幻工程里把活干完。

虚幻盒子是虚幻引擎的 **agent harness** —— 一套装在你本机的运行环境，给 AI Agent 配齐工具、素材和权限边界，让它去动真实的工程：放 Actor、改蓝图节点图、连材质、跑 PIE、编译 C++。改动落在工程里，不是一段让你自己去粘贴的代码。

产品的主体是这个 Agent，其余模块为它服务。

## Agent 靠什么干活

**模型** —— 你自己配一家服务商。内置约七十个条目，覆盖国际厂商、国内厂商、订阅账号，以及 Ollama、LM Studio 这类本机推理。密钥加密存在本机，不经中转服务。见[配置模型](/guide/ai-setup)。

**工具** —— 一次具体操作：放一个 Actor、读一份材质的节点图、把一段代码编译掉。内置一百多个，覆盖关卡、蓝图、材质、几何体、UMG、Sequencer、PCG、C++ 和内容浏览器。见[助手能做什么](/guide/capabilities)。

**技能** —— 一组做法说明，规定某类任务的处理流程、已知陷阱和不适用的场景。内置 25 个。你不需要指名，Agent 自己挑。见[工具、技能与权限](/guide/tools-and-skills)。

**边界** —— 权限档位决定它能动到哪儿、什么时候停下来问你，文件访问范围决定它能读写哪些目录。默认是「帮我批准」：它自己动手，只在识别到风险操作时停下来。见[审批模式](/guide/assistant#审批模式)。

**核对** —— 干完之后有三层：本轮改动列出净结果和 diff；审查改动用只读工具回到引擎里核实一遍；第三层要求它不许凭记忆回答，每条都重新查一遍再写出实际值。见[结果核对](/guide/assistant#结果核对-三层)。

## 它要接上虚幻编辑器才干得动活

Agent 的引擎类能力全部通过随包附带的 **UnrealAgentLink** 插件下发到正在运行的编辑器，支持 UE 5.0 至 5.8。

没连上时，这些工具不会出现在 Agent 手上 —— 它会告诉你需要先打开工程，而不是编一个看起来像成功的结果。资产库、蓝图库、材质库、笔记与知识库不依赖引擎，随时可用。

见[连接虚幻引擎](/guide/plugin)。

## 其余模块的位置

这些模块各自有完整的界面，可以单独使用。在产品结构中，它们为 Agent 提供作用目标、素材、参考资料和对外接口：

| 模块                   | 对 Agent 的作用                                              |
| ---------------------- | ------------------------------------------------------------ |
| **项目库**             | 登记工程与引擎，确定 Agent 的作用目标                        |
| **资产库**             | 素材来源。Agent 从中检索素材、导入工程，也向其中写入生成结果 |
| **蓝图库 / 材质库**    | 可复用片段的仓库。Agent 在处理同类任务时检索并参考其中的内容 |
| **笔记与知识库**       | 资料来源。Agent 针对绑定的知识库检索材料，也把研究结果写回去 |
| **AI 创作、3D 查看器** | 素材生成与检查                                               |
| **命令行、MCP**        | 把这套 harness 开放给脚本和外部 AI 客户端                    |

## 开始之前

你需要自备两样东西：

- **虚幻引擎** —— 应用不含引擎。连接插件支持 UE 5.0 至 5.8。
- **模型 API 密钥** —— 用 AI 功能时需要。不想掏密钥就用 Ollama、LM Studio 跑本机模型。

不配模型也能用：资产库、蓝图库、材质库、笔记与知识库都是完整的独立工具。

平台方面，**Windows** 是主要支持平台，功能在此平台上验证。**macOS** 可构建运行，支持扫描常见共享安装目录中的引擎、手动添加引擎目录或编辑器 `.app`、检测运行中的 UE4 / UE5 编辑器及其工程路径，但 Mac 版插件二进制的构建与发布验收尚未完成。**Linux** 可构建运行，引擎自动发现尚未适配需手动添加，安装包不含 `uebox` 命令行工具。Blender 互联管线目前仅支持 Windows。

## 社区版

本文档描述的是社区核心版，采用 Apache-2.0 许可。

- 不需要账号。应用内没有登录入口，也不做试用期或区域判断。
- 本地功能不依赖网络。未配置更新源的安装包不发起更新请求；模板源未启用时不请求模板列表。
- 模型 API 密钥保存在本机，加密存储，不经过中转服务。
