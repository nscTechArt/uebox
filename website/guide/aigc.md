# AI 创作（生图）

出概念图、贴图、UI 草图、参考图，产出直接落进资产库。

侧边栏「更多」里的 **AI 创作**。左侧是参数面板，右侧是生成历史。

![AI 创作](/shots/aigc-studio.png)

3D 模型生成是另一条路，见 [3D 生成与查看器](/guide/model3d)。

## 配置

**设置 → 模型 → 添加服务商 →「图片生成」分组**，挑一家填密钥。确认那个模型勾了「**生图**」能力，再到「默认模型 → 生图」指向它。

没配好时页面会直接挡下来：「还没有可用的生图模型」，带一个「去配置模型」按钮。面板顶部也会显示当前用的是哪个模型，来自 设置 → 模型 的「生图」角色，旁边可以「切换」。

## 文生图与图生图

**不加参考图** = 文生图，填「描述」。例如：

> 一只可爱的柴犬坐在樱花树下，水彩画风格，高清细节。

**加了参考图** = 图生图，「描述」变成「**编辑指令**」。例如：

> 保留主体和服装，把背景改成雨夜街道，电影感光影，突出人物。

### 参考图的三种来源

1. 拖进去
2. **Ctrl + V 粘贴**（面板上直接提示了这一条）
3. 点「**参考库**」

参考库固定读取 AIGC 资产库中的指定目录，界面显示「当前还能添加 N 张」。目录为空时提示将图片放入 `AIGC 资产库 / {目录名}`，并提供「打开参考素材库」入口。

资产库里任何一张图也能右键「**用作参考图生成**」直接送过来。

参考图满了会提示「参考图最多 N 张」。

## 参数

### 宽高比与尺寸

有一排常用比例，点「更多比例」展开全部。

### 分辨率

可选项随模型变，面板下方会写明这个模型支持什么：

| 档位 | 说明                   |
| ---- | ---------------------- |
| 1K   | 更快出图，快速查看效果 |
| 2K   | 画质与速度更平衡       |
| 4K   | 高细节，适合最终成图   |
| Auto | 模型自动选择尺寸       |

有些模型走的是具体尺寸而不是档位：方图 1024（速度最快）、横图 1536×1024、竖图 1024×1536、2K 方图 2048、2K 横屏 2048×1152、4K 横屏 3840×2160、4K 竖屏 2160×3840。

### 质量

Auto / 低 / 中 / 高。低档更快，适合草图验证；高档细节更多。

::: warning 部分模型按质量档位计费
面板会提示「GPT Image 2 使用质量档位计费」这类说明。调高档位直接对应更高的花费。
:::

### 生成数量

支持一次生成多张，也可填写自定义数量。批量提交时任务**间隔 1.7 秒**依次发出，完成后提示「已提交 N 个任务」；存在失败时提示「已提交 X 个，Y 个失败」。

### 负面提示词与高级参数

在「高级参数」里。

## 优化提示词

「优化提示词」由模型重写描述。存在参考图时会**结合参考图**优化，并提示「已根据参考图优化提示词」。

![提交之后：中间是进度，右侧历史里那一条显示「生成中」](/shots/aigc-generating.png)

## 生成历史

右侧整块是历史，按时间分组（今天 / 昨天 / N 天前 / 具体日期 / 更早）。

![生成完成：左边参数、中间大图、右边历史](/shots/aigc-result.png)

**筛选**：全部 / 进行中 / 已完成 / 失败。

**搜索**：按提示词、模型、风格搜。

**排序与视图**：最新优先 / 最早优先，画廊模式 / 列表模式。

每张卡片显示状态（排队中 / 生成中 N% / 已完成 / 失败）、张数、参考图数量和相对时间。

**清除失败** 会删掉失败记录，**已生成的资产不会被删除**。

## 对一张图能做什么

大图预览的顶部工具栏和历史卡片的「⋯」是同一套操作：

| 操作             | 说明                                     |
| ---------------- | ---------------------------------------- |
| 用作参考图       | 直接拿它当下一轮的参考                   |
| 复制图片         | 到剪贴板                                 |
| 下载图片         |                                          |
| **填回这套参数** | 把这次的参数回填到左侧表单，在此基础上改 |
| 复制提示词       |                                          |
| 在资产库中定位   | 生成的图会进 AIGC 资产库                 |
| 删除记录         |                                          |

::: tip 删除记录不删图
「记录删除后无法恢复。已存进资产库的图片不受影响。」
:::

## 生成的图存在哪

进 **AIGC 资产库**。历史面板顶部有「打开资产库」直达。

找不到那个库时会提示「找不到 AIGC 资产库」。

## 助手也能生图

在 AI 会话里直接说要什么图，或者点输入框的「**图片生成**」进生图模式。走的是同一个「生图」默认模型。

助手还有一条专门的路：把 UE 里的白盒截下来当参考图，让模型画成概念图 —— 见[白盒出概念图](/guide/capabilities#镜头与成片)。

::: tip 重做需要用户确认
生图按次计费，结果是否符合预期属于主观判断。助手不会自行决定重新生成，它认为结果不理想时会询问，由用户决定是否重试。
:::
