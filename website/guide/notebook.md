# 笔记与知识库

把资料喂给它，然后针对这批资料提问 —— 而不是让它凭训练数据猜。

侧边栏「更多」里有两项独立功能：

- **笔记** —— 文本记录
- **知识库** —— 导入一批资料后针对其提问，并生成派生内容

两者也是 Agent 的资料来源：会话可以绑定知识库（`/wiki`），Agent 从中检索材料，也把深度研究的结果写回去。

![知识库列表](/shots/notebooks.png)

## 笔记

块编辑器，输入 `/` 唤出命令菜单：标题、项目符号列表、编号列表、待办列表（带复选框）、引用、代码块、表格、分割线。

AI 会话里的回复可以直接保存成笔记。

![笔记编辑器](/shots/note-editor.png)

::: tip 笔记也是知识库的一种来源
笔记本身没有独立的「存到哪个库」的概念 —— 它是知识库里的一种来源类型。在 AI 会话里用 `@` 可以直接提及某条笔记。
:::

## 知识库

### 列表页

分类：**全部** / **我的知识库** / **精选知识库**。可以按最近或名称排序，网格视图或列表视图切换。

每个库显示来源数量和生成数量。

新建、重命名、删除（**不可恢复**）、上传封面（图片不超过 5 MB）。

### 一个知识库里有什么

三块：**来源** + 针对来源的**对话** + **工作台产出**。

## 来源

### 加来源

点「添加来源」，支持的类型：

| 类型         | 说明               |
| ------------ | ------------------ |
| **Web**      | 网页               |
| **YouTube**  |                    |
| **Bilibili** |                    |
| **文本**     | 直接粘，或添加笔记 |
| **文件**     | 本地文件           |

还能直接从已连接的 UE 工程里抓：

- **项目信息**
- **UE 崩溃日志**
- **UE 项目配置文件** —— 引擎配置 / 游戏配置 / 编辑器配置 / 输入配置

适用于排查崩溃和核对配置。

::: warning 音频只存不转写
音频会作为附件保存，可以打开原文件播放，**暂不提供音频转写**。
:::

### 在网络中搜索新来源

来源面板上的「在网络中搜索新来源」：输入检索内容，结果支持多选，通过「添加选中项」批量加入。

旁边的「输入想深度研究的问题」入口走[深度研究](/guide/capabilities#应用自身)流程。

### 网页清洗

网页抓回来之后会做一次清洗，去掉导航、广告这类噪音。每条来源可以在「**看原文**」和「**看清洗后**」之间切换，提示写着「这是抓回来的原文，AI 用的是清洗后的版本」。

清洗失败时会说明具体原因：

| 提示                                             | 含义                             |
| ------------------------------------------------ | -------------------------------- |
| 没能清洗掉网页噪音，用的是抓回来的原文           | 清洗没成，退回原文，仍然可用     |
| 这个页面太长，一次最多写 N token，整篇写不下     | 受「轻量任务」模型的输出上限限制 |
| 模型没有返回内容                                 |                                  |
| 清洗结果只有 N 字（原文 M 字），像是写到一半停了 | 结果可疑，**没有采用**           |

### 网页里的图片

**设置 → 知识库 → 网页导入 → 读取网页里的图片**。开启后会识别网页图片中的文字，标注成「**AI 识别**」，**原文不改动**。

完成后提示「已从 N 张图里读出文字」。

::: warning 默认关闭，因为会产生模型费用
开启后还能限制每篇最多识别几张。
:::

## 上下文档位

这是知识库里最需要理解的一个机制。

每条来源可以设定这次送多少内容给模型：

| 档位           | 说明       |
| -------------- | ---------- |
| **全文**       | 整篇送进去 |
| **只给摘要**   | 只送摘要   |
| **不进上下文** | 这次不用它 |

点来源上的标签可以在「全文」和「只给摘要」之间切换。也可以**批量设置**：全部给全文 / 全部只给摘要 / 全部不进上下文。

面板上实时显示预算：「本次送入 X 字 / 上限 Y 字 · N 个来源」。

超出上限时会点名：

> 超出上限，有 N 个来源这次送不进去：{标题}。把它们降到「只给摘要」或取消勾选。

摘要尚未生成的来源，本次先送入正文开头，并提示可点击该来源的「摘要」标签立即生成。

## 索引与召回

### 建索引

知识库检索需要**嵌入模型**：设置 → 模型 → 默认模型 → **嵌入**。未配置时检索不可用。

来源面板上的「索引选项」里有：

- **编辑后自动索引** —— 改完笔记自动更新
- **更新索引** —— 手动跑一次

设置 → 知识库 → 数据管理里还有「**重建知识库索引**」。

::: warning 更换嵌入模型会自动重建整个索引
库大的话要等。用 Ollama 的本地嵌入模型可以避免云端费用。
:::

### 测试召回率

来源面板上有「**测试知识库召回率**」：输入一段内容，看它能召回哪些片段。

结果里给三个信息：**匹配距离**、**关键词命中**、**来源**。

觉得知识库答得不准时，先用它看看是检索没召回到，还是召回到了但模型没用好。

## 提问

添加来源后即可针对这些内容提问，回答会引用具体来源（「参考资料」）。

可以「全选 / 取消全选」来源，界面上会显示「应用了 N 个来源」。一个都没选时会提示「请至少选择一个来源」。

## 工作台

把这堆资料转换成别的形态：

| 产出         | 说明                                                                                                                                                                                     |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **思维导图** | 结构化的树                                                                                                                                                                               |
| **知识图谱** | 概念关系网。节点分类贴 UE：类 / API、功能 / 系统、节点、资产类型、工作流、格式 / 标准、设置 / 属性、工具 / 软件、平台、插件、问题 / 报错、解法、概念。关系有「是一种」「包含」「属于」等 |
| **总结报告** | 一篇文字总结                                                                                                                                                                             |
| **信息图**   | 一张图讲清楚，可下载、复制到剪贴板                                                                                                                                                       |
| **知识网页** | 可浏览的页面。分两步生成：先出 Brief，再照 Brief 排版                                                                                                                                    |
| **视频概览** |                                                                                                                                                                                          |
| **模拟面试** | 基于资料出题考你，逐题给 AI 点评和参考答案，结束后有答题回顾和得分                                                                                                                       |
| **头脑风暴** |                                                                                                                                                                                          |

产出可以按类型、状态（生成中 / 已完成 / 失败）、时间（今天 / 近 7 天 / 更早）筛选，也可以按最新 / 最早 / 名称排序。

::: warning 生成会产生模型费用
提示「模型服务商返回『余额不足』」时，是所配置服务商的账户问题，需到该服务商的控制台充值，或在 设置 → 模型 更换模型。
:::

## 在 AI 会话里用知识库

不用切到知识库页面也能用：

- `/wiki [关键词]` 把一个知识库绑定到当前会话，`/wiki clear` 解绑
- `@` 提及某条来源或笔记

见 [AI 会话 · 斜杠命令](/guide/assistant#斜杠命令)。

## 让助手去查，查完存进来

知识库里原来有「网页」和「深度搜索」两个搜索页签，都删了 —— 它们是助手本来就会做的事的一个更弱的复刻。现在这件事回到对话里：

> 查一下 X，有用的存进来

助手会拆子问题、检索、**读页面正文**、对照已有来源、处理来源之间的冲突，然后把它认为值得留下的存成来源。每存一条都要你确认。

跑的是你自己配好的对话模型 + 内置浏览器，一次请求都不经过我们的服务端，也不需要任何第三方研究服务的 Key。

::: tip 报告里的几条硬规矩
这些写在助手的做法说明里，读它的产出时可以照着核：

- **只引用它真的打开过的页面。** 搜索结果摘要不算读过。
- **「没查到」是一个结论，不是失败。** 它会如实说哪个子问题没答上来，而不是编一个看起来合理的答案。
- **说清是谁说的。** 论坛里一个用户猜测代码怎么跑，和维护者说明它实际怎么跑，URL 是同一个，但不是同一种证据。
- **它自己写的东西不是来源。** 之前存进知识库的总结，下次检索会跟别的来源一样冒出来 —— 认出是自己写的就回原始页面重查，而不是拿自己给自己作证。

:::

::: warning 三种查不动的情况

- **登录墙和验证码**：不会绕，会去找公开来源或如实报告缺口。
- **纯 JavaScript 渲染的页面**：正文读回来是空的。它会去找同样内容的静态页，而不是下结论说这个话题没有资料。
- **检索后端本身出问题**：搜索一直返回不相关结果时它会明说并停下 —— 那种情况看起来和「这个话题没有答案」一模一样。

:::
