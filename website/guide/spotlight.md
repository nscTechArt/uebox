# 快捷提问（Spotlight）

两个悬浮窗口，不用切回主界面也能用：**Spotlight** 负责搜和转发，**MiniChat** 负责对话。

## Spotlight

一个悬浮搜索框。快捷键在 **设置 → 快捷键 →「呼出/隐藏快捷提问窗口」**，默认 `Ctrl+Shift+Space`。

窗口固定 600×400，记住上次拖动到的位置 —— 输入框左侧的四向箭头是拖拽手柄。点击框外或窗口失焦时自动收起。

### 结果

输入内容后最多显示 11 条：

| 段         | 条数   | 选中之后                                       |
| ---------- | ------ | ---------------------------------------------- |
| 与 AI 对话 | 1      | 打开 MiniChat 小窗，带着这句话继续对话         |
| 项目       | 最多 5 | 直接打开对应的 `.uproject`                     |
| 资产       | 最多 5 | 跳转到「资产管理」并定位到这份资产所在的文件夹 |

项目按名称搜项目库，资产按名称搜**当前活跃的**资产库。上下箭头切换，回车执行。

::: tip 选中「与 AI 对话」的那一刻会抓一次编辑器状态
按下回车就是「发送」，所以快照在这一刻抓，而不是等小窗起来再抓 —— 建窗口加载页面要半秒多，这半秒里你完全可能已经切回引擎换了选区。

抓取和开窗**并行**，抓到了一并带入，抓不到也照常发送，不会卡住等它。
:::

## MiniChat

一个独立的悬浮对话窗，400×600，默认置顶。标题栏上可以切换置顶、最小化、关闭。

它是**完整的 Agent 窗口**，不是只能聊天的小工具：输入框提示「给 Agent 下达任务…」，能调工具、能干活。

### 三个入口

| 入口                       | 打开的是什么                               |
| -------------------------- | ------------------------------------------ |
| Spotlight 的「与 AI 对话」 | 带着那句话和编辑器快照开一段新对话         |
| `Ctrl+Shift+M`             | 直接开关小窗                               |
| AI 会话的「侧边问一句」    | 带着主对话上下文开一个**只读**的窗口，见下 |

::: warning `Ctrl+Shift+M` 不在快捷键设置里
它是写死的，改不了，也不在 设置 → 快捷键 的列表中。但「全局禁用快捷键」那个总开关管得到它。

如果按了没反应，通常是这个组合被别的软件占用了。
:::

### 附件

最多 5 张图片，单张 20 MB 以内。

### 消息操作

复制、重新生成 AI 回复、编辑自己发过的消息。

::: tip 这两项调不了
窗口透明度和「保存对话历史」有对应的设置面板，但它被特性开关关掉了，菜单里没有这一项。两者目前都是固定值。
:::

## 侧边问一句

在 AI 会话里点「**侧边问一句（带上下文）**」，会把当前对话的上下文**复制**一份给 MiniChat，在那边问。

它解决的是这一刻：Agent 跑了二十步，屏幕上滚过一堆工具调用，你想问「它现在到底在干嘛」「刚才那个材质为什么建了两次」。在主对话里问这句有两个代价 —— 得等它停下来，而且这句闲聊会永久留在上下文里，之后每一轮都带着它去发请求。

侧边窗口两个都没有：问完关掉，主对话一个字都不知道。

::: danger 侧边窗口是只读的
它固定走只读档，内核只给它注册只读工具。它能看、能查、能解释，**动不了工程**。

主对话正跑着的时候让第二个 Agent 也去改同一个工程，等于两个人抢一支笔。
:::

窗口顶部的横幅会说清三件事：借了多少条上下文、这是快照还是实时、这边动不了工程。主对话还在跑时横幅写「承接主对话的 N 条上下文（快照，主对话还在跑）」。

当前对话还没有过 Agent 会话时开不了 —— 那样打开等于新开一个空对话，模型手上什么都没有。
