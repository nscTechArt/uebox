# 蓝图库与材质库

两个库结构相同，用途也相同：**存放可以反复用的片段**。蓝图库存节点图，材质库存材质节点资产。

它们是 Agent 的片段仓库 —— Agent 处理同类任务时检索这两个库并参考其中的内容，因此名称、描述和标签的准确性会影响检索效果。它也能往里存、从里面往工程里放，见[助手能做什么 · 蓝图库与材质库](/guide/capabilities#蓝图库与材质库)。

都是纯本地的，也都在当前活跃的保管库下面。

![蓝图库画廊视图](/shots/blueprint-library.png)

## 一个条目是一个文件夹

磁盘上，每个条目是保管库里的一个**目录**，目录名自带扩展名：

| 库         | 目录               | 里面有什么                                         |
| ---------- | ------------------ | -------------------------------------------------- |
| **蓝图库** | `名字.ueblueprint` | `blueprint.json`（必需）、`cover.png`、`README.md` |
| **材质库** | `名字.uematerial`  | `material.json`（必需）、`cover.png`、`textures/`  |

这么设计是为了**东西在你自己手里**：整个目录拷得走、备份得到、换台机器还在。清单是两格缩进的 JSON，用记事本能打开看懂、能手改、能进 Git 做 diff。

::: tip 数据库只是索引
把库的数据库删掉重新扫一遍目录，你的库应该完整回来 —— 这也是手动拷进来的包能被认出来的原因。

反过来：**别往包目录里塞别的东西**。里面的 `cover.png` 和 `textures/` 属于这个包，不会被当成独立资产索引。
:::

::: warning 两种读不出来的情况

- **清单里的格式标记对不上** —— 扩展名对但内容是别的东西，一律拒读。
- **清单版本比本机新** —— 硬读会在存回去时把不认识的字段抹掉，所以宁可不读。升级应用即可。

:::

目录名是显示名洗过的结果（去掉 Windows 非法字符、截到 80 字符以内、避开保留设备名），**两者可能不一致，以清单里的名字为准**。重名按 Windows 的习惯加序号：`跳跃逻辑 (2).ueblueprint`。

## 往里存

### 新建

「新建蓝图」/「新建材质」，填名称。展开「高级设置」还能填：

- **蓝图库** —— 蓝图类型、引擎版本、描述
- **材质库** —— 材质类型、描述、备注描述

### 拖进来

把蓝图包 / 材质包文件拖到左侧的文件夹里。手动拷进保管库目录的包，下次开库扫描时也会被认出来。

### 从旧版导入

「从旧版导入」用于迁移旧版本的数据。迁移完会打一个一次性标记防止重复迁移，**旧数据不会被删掉** —— 万一迁移出岔子还能捞回来。

## 找出来

顶部一排是通用的：

| 控件     | 说明                                           |
| -------- | ---------------------------------------------- |
| **搜索** | 蓝图库搜名称/类型/标签，材质库搜名称/路径/标签 |
| **筛选** | 「★ 只看收藏」                                 |
| **排序** | 最近使用（材质库是最近更新）/ 名称 / 创建时间  |
| **视图** | 网格 / 列表                                    |

**材质库多两个筛选面**：混合模式、着色模型，还有一个「有依赖贴图」的开关。

![材质库画廊视图](/shots/material-library.png)

### 列表视图的列

两个库的列表视图使用通用表头：

- **蓝图库** —— 名称、蓝图类型、引擎版本、统计、标签
- **材质库** —— 名称、材质类型、混合与着色、统计、路径

### 统计列写了什么

- **蓝图** —— N 函数、N 变量、N 图表、N 组件。什么都没有的显示「空蓝图」
- **材质** —— 参数 N · 依赖 N

这一列是判断「这个片段有没有内容」最快的方式。

## 文件夹

左侧是文件夹栏，可以新建、重命名、删除，拖动边缘调宽度。

::: tip 文件夹是筛选，不是归档
删掉一个文件夹，里面的东西**回到「全部」，不会被删除**。
:::

## 集合

多个蓝图（或材质）可以打成一个**集合**，作为一张卡片管理，卡片上标着里面有几个。

集合不属于任何单个条目，所以它存在保管库根目录的一份单独文件里，**跟着保管库走** —— 拷走整个保管库文件夹，集合也在。两个库共用这一份文件。

排序方式、视图模式、筛选条件这类界面偏好不在里面，它们只存在本机。

## 卡片操作

右键或列表行上的按钮：

| 操作                  | 说明                                               |
| --------------------- | -------------------------------------------------- |
| **修改封面**          | 选一张图片或一段视频                               |
| **录制封面**          | 打开快速录制窗录一段，见[录屏](/guide/small-tools) |
| **恢复默认封面**      |                                                    |
| **编辑信息**          | 名称、描述（材质库还有备注描述）                   |
| **收藏 / 取消收藏**   |                                                    |
| **删除 / 移出材质库** |                                                    |

::: warning 删除暂时不能撤销
弹窗原话：「『{名称}』会从蓝图库中移除。这个操作暂时不能撤销。」
:::

## 「有 N 项没能存进保管库」

出现这条提示时，**后续编辑同样无法保存**，需要先处理。

两个常见原因：

1. 切换了保管库
2. 包目录在资源管理器里被改名或移走了

处理完点「重试保存」。

## 空库的时候

蓝图库会提示「蓝图库还是空的 —— 新建一个蓝图节点，或者从旧版导入你已有的蓝图。」

材质库的空状态会区分两种：一个都没有，和筛选条件没命中（「你可以调整筛选条件，或者新建一个离线材质节点条目。」）。

## 开库要走一遍磁盘

开库时会递归遍历保管库、逐个读一次清单，所以条目多的库开起来会有可感的延迟。本地固态盘上五百个条目约三百毫秒，异步进行，不挡界面。

::: warning 网络协作库上没有量过
每次读目录、读文件都是一次网络往返，慢一到两个数量级完全可能。两个库目前都建议放在本地保管库里。
:::

## 云同步

蓝图库的云同步已经整体下线，社区版和商业版都没有。目前两个库都是纯本地的。
