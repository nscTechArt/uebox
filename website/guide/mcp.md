# MCP

给助手接上别人的工具，或者把盒子的虚幻引擎能力开放给别的 AI 客户端。

MCP（Model Context Protocol）是一套让 AI 客户端和工具服务互相对接的协议。应用在这条协议上做两件方向相反的事：

- **往里接** —— 把第三方 MCP 服务接进来，扩展助手的能力
- **往外开** —— 将应用的虚幻引擎能力开放给 Claude Code、Cursor 等外部客户端

设置入口：**设置 → MCP**。页面分上下两部分。

![设置 → MCP](/shots/settings-mcp.png)

## 往里接：第三方 MCP 服务

### 添加一条服务

点「添加服务」，填：

| 字段         | 说明                                             |
| ------------ | ------------------------------------------------ |
| **标识**     | 字母、数字、下划线、连字符，最长 32 位，不能重复 |
| **连接方式** | 本地命令（stdio）或远程服务（HTTP）              |
| **启动命令** | stdio 方式填这个                                 |
| **服务地址** | HTTP 方式填这个                                  |
| **环境变量** | 每行 `KEY=VALUE`，也可以直接粘贴 JSON            |
| **停用**     | 保留配置但不连接                                 |

填完点「**保存并连接**」。连上之后这一条会显示「已连接 · N 个工具」；连不上显示「连接失败」，旁边有「重新连接」。

### 直接粘 Claude Desktop 的配置

本页接受 Claude Desktop 格式的 JSON，不需要逐字段转写。

### 配置文件

页面上会显示配置文件路径，旁边有「打开位置」和「复制」。

::: danger 删除服务不可撤销
删掉一条服务时，填好的启动命令和环境变量会一起没有。
:::

### 保存不了

有配置填写不完整时「保存」是灰的，并会提示「有 N 条配置填写不完整，修好之后才能保存」。常见的是标识为空、标识重复、环境变量格式不对。

## 虚幻引擎自带的工具集

连接的工程使用 **UE 5.8 或更高版本**时，应用自动接入引擎官方的 MCP 工具集，在页面上标记为「**自动发现**」。该条目不需要手动配置。

### 开启

引擎侧没开的话，这里有一个「**一键开启**」按钮。

它会更新项目文件和编辑器偏好。**完成后需要重启虚幻编辑器** —— UE 没法热加载新的插件模块，这一步绕不过去。开启后可以在虚幻的 `Edit > Plugins` 里关掉。

状态会如实显示：

| 显示                     | 含义                  |
| ------------------------ | --------------------- |
| 已配置 · 请重启编辑器    | 配置已写入，需重启 UE |
| 已开启 · 运行中          | 正常工作              |
| 引擎版本过低 · 需要 5.8+ | 这个工程用不了        |

### 看不到这块

「还没有连接的虚幻引擎项目」—— 先在项目库里打开一个工程，这里才会显示它能不能用。

刚更新过应用且显示检查失败时，重启应用后再查看。

### 「怎么只有三个工具」

显示的数字是**入口数**，不是工具数。每个入口内部包含多种引擎操作，助手会按任务需要挑。

## 往外开：共享虚幻引擎能力

开启「**开放给外部客户端**」后，Claude Code、Cursor 等客户端可以直接操作引擎。

**仅本机可连，需要令牌，默认只读。**

### 接上去

页面下方有一块「**连接配置**」，点「复制配置」，粘贴到外部客户端的 MCP 配置文件里即可。令牌出于安全只显示头尾，要完整的用「复制令牌」。

### 权限

「外部客户端的权限」默认是**只读**，页面上会直说当前档位：

- 「当前只读。打开后允许外部客户端创建、修改和删除。」
- 「当前可写：外部客户端能创建、修改和删除你的资产。」

::: danger 开放写权限前需要了解这四条

1. 外部客户端的调用**不弹出审批窗，写操作直接执行**。应用内助手的逐步审批不适用于外部客户端。
2. 读写本地文件和执行命令的工具**在任何情况下都不对外开放**，无论权限档位。
3. **令牌泄露意味着持有者可以修改工程中的资产。**
4. 怀疑泄露就点「**重置**」。重置后所有已配置这个服务的外部客户端会立刻连不上，需要重新粘贴配置。

:::

### 端口

默认端口可以改，范围 1024–65535。**服务运行中改不了**，需要先关掉上面的开关。

### 工具数量

「运行中 · 已开放 N 个工具」统计的是**应用自身的引擎工具总数**，与上方第三方服务的数量不是同一口径。

### 自动运行

开关状态会保留，下次启动应用时自动运行。

## 和「工具」设置页的关系

第三方 MCP 带入的工具**不出现在 设置 → 工具 的清单里**，由本页管理（连接哪台服务器、是否开放写操作）。
