# 文件都放在哪

要备份、要迁到新机器、要确认某样东西有没有离开过这台电脑 —— 都从这页查。

## 应用数据目录

设置、对话记录、技能、日志都在系统的应用数据目录下，文件夹名是 `unreal-box`：

| 系统    | 路径                                        |
| ------- | ------------------------------------------- |
| Windows | `%APPDATA%\unreal-box\`                     |
| macOS   | `~/Library/Application Support/unreal-box/` |
| Linux   | `~/.config/unreal-box/`                     |

主要内容：

| 文件 / 目录                             | 是什么                              |
| --------------------------------------- | ----------------------------------- |
| `app-settings.json`                     | 应用设置                            |
| `models.json`                           | AI 服务商与模型配置（**不含密钥**） |
| `ai-provider-secrets.bin`               | 加密后的密钥                        |
| `object-storage.json`                   | 对象存储的连接配置（**不含密钥**）  |
| `object-storage-index.json`             | 传到对象存储的文件登记              |
| `instructions.md`                       | 给助手的常驻说明                    |
| `skills/`                               | 技能目录                            |
| `disabled-skills.json`                  | 关掉了哪些技能                      |
| `plugins/`、`disabled-plugins.json`     | 插件                                |
| `mcp.json`                              | 接入的第三方 MCP 服务               |
| `mcp-server.json`                       | 对外开放的 MCP 服务配置             |
| `agent-v3-sessions/`                    | 会话内核的记录                      |
| `chat-history/`                         | 对话历史                            |
| `organize-ledger/`                      | 内容整理的操作台账（撤销用）        |
| `template-sources.json`                 | 模板源                              |
| `templates/`                            | 本地模板库                          |
| `list-thumbnails/`                      | 缩略图缓存                          |
| `logs/`                                 | 日志。报问题时附上它                |
| `diagnostics/`、`diagnostics/recovery/` | 诊断与恢复数据                      |
| `window-state.json`                     | 窗口位置与大小                      |
| `spotlight-position.json`               | 快捷提问窗口的位置                  |

::: tip 界面上有直达按钮
技能目录、MCP 配置文件、AI 服务商配置、命令行程序位置，各自的设置页里都有「在文件夹中显示」或「打开位置」。不用自己照着路径翻。
:::

## API 密钥

密钥**不在明文文件里**。

| 填法           | 存在哪                                                 |
| -------------- | ------------------------------------------------------ |
| 直接填写       | 加密保存在 `ai-provider-secrets.bin`，用系统的凭据存储 |
| 环境变量名     | 只存变量名，密钥不进应用的任何文件                     |
| `!` 开头的命令 | 只存命令，密钥不进应用的任何文件                       |

系统加密不可用时界面会提示「无法安全保存密钥」，这时候用后两种方式。

应用没有中转服务器，密钥只用于直接连接所配置的 API 地址。

## 素材位置

位置在建库时指定：

| 情况                  | 文件在哪                                 |
| --------------------- | ---------------------------------------- |
| 资产库 · 引用原有文件 | **保持原位**，应用只存索引               |
| 资产库 · 复制并归档   | 复制到建库时选的保存位置                 |
| 资产库 · 网络协作库   | 共享盘或服务器上，本地只有缓存和连接记录 |
| 蓝图库 / 材质库       | 包文件在当前保管库目录下                 |
| AI 创作生成的图       | AIGC 资产库                              |
| AI 生成的 3D 模型     | 当前保管库的 `AIGC\模型\<任务ID>`        |

::: tip 数据库只是索引
用户创作的东西，唯一真相源是磁盘上的文件。库里的数据库是可以删掉重建的索引层 —— 这也是「拷得走、备份得到、换台机器还在」的前提。
:::

## 工程和引擎

应用**不修改**工程文件。项目库的「导入」只登记路径，「移除」只从列表中删除记录。

唯一的例外是**插件**：会写入 `<工程>/Plugins/UnrealAgentLink/` 并在 `.uproject` 里启用它。这个行为可以在 设置 → 插件 关掉，也可以按工程移除。

引擎目录应用只读不写。早期版本会往引擎目录装插件，残留可以用 设置 → 插件 →「清理旧版插件」清掉。

## 录制文件

录屏产生的文件在录制库里管理（设置 → 录屏），详情里有「文件路径」和「在文件夹中显示」。

## 卸载之后

卸载不会删除应用数据目录。需要完全清除时手动删除该文件夹。目录名为 `unreal-box`，取的是应用内部名而非显示名。

::: warning 该目录包含的内容
资产库索引、蓝图库和材质库的记录、全部对话历史、自定义技能、加密后的密钥。
:::

## 备份与迁移

要换机器或留个底，复制两部分：

1. **应用数据目录**（上面那个文件夹）
2. **各保管库的目录**（建库时指定的位置）

装好应用把这两部分放回原位就能接着用。

::: warning 加密密钥可能不跨机器
`ai-provider-secrets.bin` 用的是系统凭据存储，换一台机器不一定解得开。新机器上重新填一次密钥即可，其他数据不受影响。
:::
