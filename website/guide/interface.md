# 界面导览

认清主窗口的三块，以及那些不属于任何页面、会浮在所有页面之上的东西。

主窗口分三部分：左侧侧边栏、顶部标签页、中间内容区。

![主窗口：左侧边栏、顶部标签页、中间内容区](/shots/home-projects.png)

## 侧边栏

自上而下：品牌区、功能入口、「更多」、AI 对话列表、底部设置入口。

### 功能入口

默认常驻四项：项目库、资产库、蓝图库、材质库。

其余功能（3D 查看器、AI 创作、笔记、知识库、资产节点管理）收在「更多」中。点击「更多」在右侧展开浮层，点击浮层外区域收起。当前页面属于「更多」中的功能时，触发行高亮，但浮层不自动展开。

### 自定义常驻项

「更多」浮层内的「自定义」：

- 勾选的功能常驻侧边栏，未勾选的收入「更多」
- 拖动调整顺序
- 点「完成」保存

### AI 对话列表

侧边栏下半部分，分三段：

| 段       | 内容                 |
| -------- | -------------------- |
| **置顶** | 已置顶的会话         |
| **项目** | 按 UE 工程分组的会话 |
| **对话** | 未关联 UE 工程的会话 |

会话行显示状态标记：**已连接**、**正在运行**、**有问题等你回答**、**任务已完成，还没看**。后两者表示该会话需要处理。

**整理侧边栏**（列表顶部）提供两组选项：

- 分组方式：按 UE 工程 / 在一个列表中
- 排序：最近更新 / 创建时间 / 名称

**会话右键菜单**：置顶、重命名、归入工程、不在项目中工作、新建工程分组、删除。

**多选**：`Ctrl`（macOS `Cmd`）+ 点击逐条加选，`Shift` + 点击选择连续范围，之后可批量删除。

**项目分组右键菜单**：重命名项目、在资源管理器中打开、归档聊天、移除项目。

- **归档聊天** 将该工程下的所有对话归档，之后在 设置 → AI 助手 → 归档对话 中查看。
- **移除项目** 仅将分组从侧边栏移除，其中的对话不删除，回到「对话」段。

**添加项目**分组有两种来源：选择本机的 UE 工程目录，或从已导入的工程中选择。

### 收起与浮出

侧边栏可以收起。收起状态下鼠标移至左边缘时临时浮出，移开后收回。

拖动侧边栏边缘调整宽度，双击边缘恢复默认宽度。

## 标签页

每打开一个页面新增一个标签。

右键标签：关闭、关闭其他、关闭右侧、复制、固定。固定的标签不受「关闭其他」影响。

标签会持久化。重新打开应用时回到上次所在的标签；没有保留的标签时进入项目库。

## 切页面也不会消失的东西

以下组件挂在应用层，不属于任何一个页面 —— 你切到别处它们照样在，这是故意的：助手在后台干活时你得看得见。

| 组件               | 出现条件                                               |
| ------------------ | ------------------------------------------------------ |
| **导入进度**       | 资产导入进行中。点击卡片跳转到对应文件夹，也可中止     |
| **资产锁指示器**   | 助手锁定资产时，显示「AI 锁定了 N 个资产」，可全部解锁 |
| **敏感操作确认**   | 助手请求执行需要确认的操作时                           |
| **引擎桥接横幅**   | 桥接不可用时                                           |
| **全局音频播放器** | 播放生成的音频或朗读回复时                             |

资产库页面底部另有一条状态栏，仅在该页面显示。

## 主题

设置 → 外观：跟随系统 / 浅色 / 深色 / 自定义。自定义模式可设置主色、辅色、强调色，设置时校验对比度。

「减少动态效果」三档：跟随系统 / 开启动效 / 减少动效。

## 独立窗口

以下界面运行在独立窗口中，不在主窗口内：

| 窗口         | 打开方式                                                   |
| ------------ | ---------------------------------------------------------- |
| 快捷提问     | 全局快捷键，见 [Spotlight](/guide/spotlight)               |
| 快捷问答小窗 | 快捷提问的「与 AI 对话」、`Ctrl+Shift+M`、或「侧边问一句」 |
| 快速录制窗   | 从蓝图库/材质库「录制封面」或资产库详情面板打开            |
| 区域选择遮罩 | 录制选区时                                                 |
| Agent 浏览器 | 浏览器显示方式设为「独立窗口」时                           |
