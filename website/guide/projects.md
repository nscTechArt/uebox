# 项目库

把你的工程登记进来，Agent 才有作用目标 —— 只有登记并连上的工程它才能操作。

侧边栏第一项，也是应用的默认落点。上面是**引擎版本**，下面是**我的项目**。

![项目库](/shots/home-projects.png)

## 引擎版本

启动时会扫描本机已安装的虚幻引擎。每个版本可以：

- **启动** —— 不带工程直接打开编辑器
- **设为默认** —— 部分操作需要一个默认引擎
- **安装目录 / 插件目录** —— 打开对应文件夹
- **移除引擎** —— 只从列表移除，**不删除硬盘上的引擎文件**

点右上角「刷新」重新扫描。发现已失效的引擎记录时会询问是否清理，该操作同样只修改列表。

::: tip 一个都没扫到
「没有找到已安装的虚幻引擎」不一定代表没装。把引擎根目录（包含 `Engine/Binaries/Win64/UnrealEditor.exe` 的那一层）**拖到这块区域**，或者点 `+` 手动添加。

Epic Games Launcher 装的引擎请在 Launcher 里管理。
:::

「扫不动」和「真的没装」是两回事。点刷新失败时会提示「扫描引擎失败，列表可能不全」；列表空着时的文案是「没有找到已安装的虚幻引擎」。读不出来那次会明说「这不代表你没装引擎 —— 这次没读出来」。

## 导入工程

盒子**不扫你的硬盘找工程** —— 你自己指给它，三种方式随便挑：

1. 把 `.uproject` 文件或工程目录**拖到页面上**
2. 点「**导入已有工程**」选文件
3. 拖入**包含多个工程的目录**，可选择全部导入或勾选其中若干个

导入只将路径登记到列表，**不移动、复制或修改工程文件**。

批量导入完会给一份汇总，按段拼出来：「成功导入 N 个、M 个已存在、K 个失败」。「已存在」是最常见的结果 —— 把上周导过的目录再拖一次就是它。

## 新建工程

「创建项目」→「**用模板新建工程**」。

### 模板市场

模板分两类来源：**我的**（本地模板库）和**社区**（线上模板源）。

::: warning 默认不联网
模板存放在线上模板源中。应用默认不启用模板源，**未启用时不发起网络请求**；启用后才会获取模板列表。

官方源有 **GitHub** 和**国内镜像**两份，建议一起启用，哪个通就用哪个。
:::

**筛选**：来源（社区 / 我的）、用途（游戏 / 渲染 / 影视 / 建筑 / 汽车 / 其他）、引擎版本。带搜索框，顶部显示「N / M 个模板」。

**排序**：推荐排序 / 按名称 / 按大小 / 最近添加。

社区模板要先**下载到本地模板库**才能拿来建工程。

::: danger 社区模板未经审核
原话：「社区模板由第三方提供，未经官方审核。安装前请确认来源可信。」
:::

部分源连接失败时提示「有 N 个源没连上，模板列表来自其它源」，或具体到「源『{名称}』获取失败：{原因}」。源中存在不合规条目时提示「有 N 条不合规条目已被忽略」。

### 管理模板源

「管理模板源」里可以看到内置源，也可以添加或删除自己的源。

### 添加自定义模板

「添加自定义模板」：填模板名称，选一个源工程路径，就把那个工程存成模板。

### 建工程

选模板 → 填工程名称 → 选保存位置 → 「创建」。

## 工程卡片

右键菜单：

| 菜单项                      | 说明                                       |
| --------------------------- | ------------------------------------------ |
| 打开项目                    | 用对应版本的引擎启动                       |
| 打开 C++ 工程               | 打开 `.sln`，没有会提示「未找到 sln 文件」 |
| 打开目录                    | 打开工程文件夹                             |
| 更换封面                    | 换卡片上的图                               |
| 重命名                      | **只改应用里显示的名字**                   |
| 置顶项目                    | 固定在列表最前，卡片上标「已置顶」         |
| 安装 / 移除 UnrealAgentLink | 见[连接虚幻引擎](/guide/plugin)            |
| 移出「{分组}」              | 从分组里拿掉，仍在总列表                   |
| 移除项目                    | 从列表移除，**不删除工程文件**             |

## 分组

右键空白处 →「创建分组」。分组在界面上是**列表上方的一条筛选按钮**，不是文件夹：

| 按钮       | 看到的                 |
| ---------- | ---------------------- |
| **全部**   | 所有工程               |
| **未分组** | 还没归进任何分组的工程 |
| 分组名     | 只看这个分组里的工程   |

往分组里加工程：**把工程卡片拖到那个分组按钮上**。拿出来用右键的「移出「{分组}」」。

::: tip 分组里没有任何东西是不会丢的

- 「移出分组」只是从分组里拿掉，工程仍在总列表。
- 「解散分组」的原话是「分组会消失，里面的工程会回到『未分组』，一个都不会删」。

:::

## 搜索与筛选

支持按工程名搜索，按引擎版本筛（含「版本未知」）。

三种「看不到东西」的提示是分开的，不要混：

| 提示                       | 含义                           |
| -------------------------- | ------------------------------ |
| 没有匹配「{关键词}」的工程 | 搜索条件没结果，清空搜索框     |
| 没有「{版本}」的工程       | 版本筛选没结果，换一个或选全部 |
| 没能读到工程列表           | **这次读取失败**，刷新重试     |

## 工程不在了

打开一个已经被删掉或移走的工程时，弹窗写「这个工程已经不在电脑上了」，并给出它记的那个路径，可以选择「从列表移除」。

点「刷新」时如果发现一批这样的记录，会问「发现 N 个失效项目记录，是否将这些失效项目从列表中移除？」—— **该操作不会删除磁盘上的项目文件**。一个都没有时提示「未发现失效项目记录」。

## 打开工程之后

**设置 → 项目库 → 打开工程后隐藏主界面**：开启后从应用内启动工程时，主界面收入托盘，后台任务继续运行。默认关闭。

## 插件没装上的提示

导入工程时如果插件没装成功，弹窗标题是「**工程导入了，但 AI 连不上这个引擎**」，正文写明具体原因。三种原因和各自的处理见[连接虚幻引擎 · 导入工程时提示插件没装上](/guide/plugin#导入工程时提示插件没装上)。

主按钮是「**让 AI 看看**」—— 点它会新开一条会话，把工程路径和盒子报的原因码原样交给助手，并指明从哪几处查起（`.uproject` 读不读得出、`EngineAssociation` 写的是哪个版本、插件目录在不在、这台机器装没装对应引擎）。

也可以事后从工程卡片右键手动安装。
