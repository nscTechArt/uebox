# 资产节点管理

侧边栏「更多」里的**资产节点管理**。这一页是给**管理资产服务器的人**用的：连节点、建资产库、管成员。

只是想连上团队的库用一用，看[团队协作](/guide/asset-team)就够了，不用进这一页。

![资产节点管理](/shots/server-management.png)

## 连接节点

**连接配置**一段：

1. 填**服务器地址**，点「连接」
2. 选**身份**，两种：

| 身份           | 用途                                     |
| -------------- | ---------------------------------------- |
| **成员账号**   | 普通用法，填账号和密码                   |
| **所有者 KEY** | 所有者和恢复管理用，**不要发给普通成员** |

登录后显示「已登录：{账号} / {角色}」。

页面顶部的状态是四档：已连接 / 连接中 / 连接失败 / 未连接。

## 资产路径与资产库

服务端是两层结构：

- **资产路径** —— 分组层，比如 `/volume1/UE资产库/项目A`
- **资产库** —— 挂在资产路径下面，就是大家平时用的那个库

### 新增资产路径

点「资产路径」，填显示名称（留空取目录名）和服务器路径（必填，例如 `/volume1/UE资产库/Project`）。

**目录不存在会自动创建。**

::: tip 分组随时能调，不动文件
一个资产库归到哪个资产路径可以随时改（右键「变更所属资产路径」），**只改归属，不移动任何文件**。所以重新分类不会让谁的引用失效。
:::

### 新建资产库

点「新建资产库」，填名称（必填）和路径（可选，留空用默认路径），选它归属哪个资产路径。

服务器上一个库都没有时，页面会给一个「创建第一个资产库」的入口。

### 资产路径的操作

| 操作             | 说明                       |
| ---------------- | -------------------------- |
| 重命名           | 只改显示名                 |
| 变更所属资产路径 | 改归属，不移动文件         |
| 移除资产路径     | 路径下还有资产库时不让移除 |
| 删除资产库       |                            |

想移除一个还有库挂着的路径，会被拦下：「该路径下还有 N 个资产库，请先移出」。

## 成员管理

**成员**一段可以添加成员：填成员账号和初始密码，选角色。

两级角色：

| 角色           | 能做什么                 |
| -------------- | ------------------------ |
| **成员**       | 按分配到的权限使用资产库 |
| **节点管理员** | 加人、建库、删库         |

## 服务端更新

检查更新需要**节点管理员身份**，其他身份提示「请以节点管理员身份检查更新」。

更新完成后服务器会重启，页面提示「更新完成，服务器即将重启」。

## 和「网络协作库」的关系

这一页管的是**服务端**：有哪些资产路径、哪些库、谁能进。

成员那头在自己的应用里用的是「新建资产库 → 网络协作库 → 资产服务器」，填你给的地址和账号，见[团队协作](/guide/asset-team#资产服务器)。

两边是同一套东西的两个入口，不要混。
